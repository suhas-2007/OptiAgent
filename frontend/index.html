OptiAgent System Architecture

Each stage searches within the supplied bounds and checks the best candidate by evaluating the objective again. The run ends at the stage, time, or evaluation limit.

1. Observe

Safe AST parsing extracts variables, validates dimensionality, and checks numerical bounds.

2. Reason

The parser checks whether coordinates can be searched independently.

3. Decide

Independent coordinates use bounded grid search. For coupled objectives, Gemini or local rules choose an optimizer.

4. Act

Each stage receives a share of the remaining evaluation budget.

5. Validate

Independent mathematical re-computation verifies bounds compliance and objective accuracy.

6. Adapt

After the configured number of stages without improvement, the next stage changes the sampling grid or restarts the optimizer.

The run file records settings, evaluations, and stage outcomes.
